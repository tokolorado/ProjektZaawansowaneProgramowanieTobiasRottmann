Opis projektu – QuizSystem
1. Cel projektu

Celem projektu było zaprojektowanie i implementacja desktopowej aplikacji quizowej w technologii .NET, demonstrującej praktyczne zastosowanie zaawansowanych zagadnień programowania obiektowego, architektury warstwowej oraz nowoczesnych narzędzi ekosystemu .NET.

Projekt kładzie szczególny nacisk na:

czytelną architekturę,

separację odpowiedzialności,

możliwość dalszej rozbudowy systemu,

zgodność z dobrymi praktykami inżynierii oprogramowania.

2. Charakterystyka aplikacji

QuizSystem jest aplikacją typu desktop, umożliwiającą użytkownikowi:

wybór jednego z dostępnych quizów,

rozwiązywanie quizu składającego się z pytań jednokrotnego i wielokrotnego wyboru,

automatyczną ocenę poprawności odpowiedzi,

prezentację wyniku końcowego wraz ze szczegółowym podsumowaniem odpowiedzi.

Aplikacja została zaprojektowana w taki sposób, aby była intuicyjna w obsłudze, a jednocześnie jasno ilustrowała zastosowane mechanizmy programistyczne.

3. Architektura systemu

Projekt został zrealizowany w oparciu o architekturę warstwową, zgodną z zasadami Clean Architecture.

Warstwy systemu:

Warstwa domenowa (QuizSystem.Core.Domain)
Zawiera logikę biznesową aplikacji, encje domenowe (Quiz, Question, Answer) oraz interfejsy definiujące zachowanie systemu. Warstwa ta jest niezależna od UI i bazy danych.

Warstwa aplikacyjna (QuizSystem.Core.Application)
Odpowiada za koordynację logiki aplikacyjnej, fabrykę danych demonstracyjnych, repozytoria oraz komunikację pomiędzy warstwą domenową a infrastrukturą.

Warstwa infrastruktury (QuizSystem.Infrastructure)
Implementuje dostęp do danych przy użyciu Entity Framework Core, konfigurację bazy danych SQLite, migracje oraz mechanizm seedowania danych.

Warstwa prezentacji (QuizSystem.Wpf)
Aplikacja WPF zrealizowana w oparciu o wzorzec MVVM (Model–View–ViewModel), odpowiedzialna za interfejs użytkownika, nawigację oraz prezentację wyników.

4. Zastosowane technologie

C# / .NET

WPF (Windows Presentation Foundation)

MVVM

Entity Framework Core

SQLite

LINQ

Repository Pattern

Git / GitHub

5. Funkcjonalności aplikacji

menu wyboru quizu,

filtrowanie quizów przy użyciu LINQ,

obsługa pytań jednokrotnego i wielokrotnego wyboru,

nawigacja pomiędzy pytaniami,

obliczanie wyniku końcowego,

wizualne oznaczenie poprawnych i błędnych odpowiedzi (kolorowanie),

podsumowanie odpowiedzi po zakończeniu quizu,

możliwość restartu quizu,

automatyczna inicjalizacja i seedowanie bazy danych.

6. Aspekty jakościowe projektu

Projekt został wykonany z uwzględnieniem:

zasad programowania obiektowego (enkapsulacja, abstrakcja),

czytelności i komentarzy w kodzie,

minimalizacji logiki w warstwie UI,

łatwości testowania i dalszej rozbudowy,

kontroli wersji z zachowaną historią zmian w repozytorium GitHub.

7. Podsumowanie

Projekt QuizSystem spełnia założenia projektu z programowania zaawansowanego, prezentując praktyczne zastosowanie nowoczesnych technologii .NET, poprawną architekturę oraz dojrzałe podejście do projektowania aplikacji.
System jest w pełni funkcjonalny, stabilny oraz gotowy do dalszego rozwoju.
