## Uruchomienie aplikacji

Gotowa wersja aplikacji znajduje się w katalogu `Release16012026`.

Aby uruchomić:
1. Wejdź do folderu `Publish`
2. Uruchom plik `QuizSystem.Wpf.exe`




Wymagania:

Windows 10 / 11

.NET SDK 10.0 (lub zgodne Preview)

Visual Studio 2022 (zalecane)

workload: .NET Desktop Development




Projektowo:

Kroki uruchomienia:

Rozpakuj archiwum ZIP

Otwórz plik:

QuizSystem/QuizSystem.slnx


Ustaw projekt startowy:

QuizSystem.Wpf


Uruchom aplikację (F5)

Pierwsze uruchomienie:

Aplikacja automatycznie:

tworzy bazę SQLite (quizsystem.db)

wykonuje migracje EF Core

seeduje dane (3 quizy)

Nie są wymagane żadne dodatkowe konfiguracje.
